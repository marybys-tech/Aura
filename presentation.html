What Surprised Us

🎨 Aura visualization was the hardest

CSS blur creates muddy colors. Canvas + additive blending was the fix. Framer Motion won for feel.

🧠 AI needs guardrails

LLMs ignore "avoid this category" — we moved quest logic to code and let AI do only creative writing.

📊 Score 0-100 is broken

Ceiling problem + invisible early progress. Level + Vitality with sqrt visual curve fixed it.

🔇 Silent fallbacks hide bugs

Fake quotes masked a broken Bedrock connection for hours. We removed all fallbacks — errors must surface.

✨ CLAUDE.md is the soul

A detailed CLAUDE.md with architecture, schemas, and code standards kept every conversation consistent.
