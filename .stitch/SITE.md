# Aura — Site Vision & Roadmap

## 1. Vision
Aura is a gamified habit-tracking dashboard where users manage habits by categories, visualize progress through an animated "Aura" character, and receive AI-powered narration and quests from an "AI Master" mentor. The UI should feel like a mystical RPG character screen — ethereal, alive, and motivating.

## 3. Pages

### Core Pages
1. **Login Page** — OAuth login (Google/GitHub), minimal and atmospheric
2. **Dashboard (Today)** — Main view: Aura visualization, today's habit cards with complete/skip, stats panel, quests
3. **Dashboard (Week)** — 7-day habit completion grid, read-only
4. **Dashboard (Month)** — Calendar view with completion summaries, read-only
5. **Habits Page** — List/manage habits, add new with category/schedule selector
6. **Habit Form** — Modal or page for creating/editing a habit

### Layout Components
7. **App Shell** — Sidebar navigation + header with avatar/theme toggle
